9.4.8 IO UART

This part is a UART serial port. This part connects the hardware/software UART IO pins of microcontroller to one real/virtual PC serial port. To use virtual port is need to install a virtual port software, as described in Chapter: Serial Communication. The serial communication uses the 8N1 format.
