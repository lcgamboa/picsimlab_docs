3.3.1 Introduction and Software Requirements

The PICSimLab Project Wizard provides a user interface for generating code projects utilizing pre-defined code templates. To facilitate compilation and debugging, the appropriate Integrated Development Environments (IDEs) must be installed prior to project creation. These IDEs are dependent on the selected boards and microcontrollers. For boards employing ESP32, STM32, Atmel (AVR), STM8, and C51 microcontrollers, the PlatformIO IDE for VSCode is required. Furthermore, for boards based on the PIC18F and PIC16F microcontrollers, the MPLABX IDE and the XC8 compiler must be installed.
