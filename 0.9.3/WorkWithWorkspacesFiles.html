3.3.2 Work With Workspaces Files

Upon saving a simulation containing a code project to a workspace file (.pzw), the project’s code is also included within the workspace file. When the workspace file is opened, it points to a copy of the stored code, not the original project code. Any modifications made to the code within the opened workspace file will be automatically saved during the file’s closing.

This feature has been added to simplify student assignment submission using PICSimLab for simulation practice. The following steps outline its usage:

  1. Students begin by opening PICSimLab and utilizing the Project Wizard to establish a new project.
  2. Next, students will develop the code and conduct the required simulations within the project.
  3. Finally, students save the workspace file and submit it for review.
  4. The instructor then receives the workspace file, containing the simulation and code developed, for grading purposes.
