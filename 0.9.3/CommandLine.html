3.5 Command Line

PICSimLab supports two command lines format:

One for load a PICSimLab Workspace file (.pzw) 

  picsimlab file.pzw

And other for load .hex/.bin files 

  picsimlab boardname [microcontroller [file.hex [file.pcf]]]

Supported boards boardname parameter:

  • Arduino_Mega
  • Arduino_Nano
  • Arduino_Uno
  • Blue_Pill
  • Breadboard
  • Curiosity
  • Curiosity_HPC
  • ESP32_C3_DevKitC_02
  • ESP32_DevKitC
  • Franzininho_DIY
  • K16F
  • McLab1
  • McLab2
  • PICGenios
  • PQDB
  • Remote_TCP
  • STM32_H103
  • X
  • Xpress
  • gpboard
  • uCboard
